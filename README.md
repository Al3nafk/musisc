# Musisc

Learn sheet music note by note: a staff diagram and plain-language lesson for each note, falling notes onto an on-screen piano, a practice mode, and a demo of the whole song.

**Open it:** https://al3nafk.github.io/musisc/

- Works offline after the first visit, and can be installed as an app from the browser menu.
- Opens MusicXML (.musicxml, .mxl), MIDI (.mid) and ABC files on your device, with no internet needed. For printed sheets, the free Audiveris app can turn a PDF or photo into MusicXML offline.
- Reading photos and PDFs directly uses Claude, so that part works in the claude.ai version of the app.
